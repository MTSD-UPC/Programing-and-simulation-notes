# CPU 型号解读

### Intel CPU 命名规则

Intel Core i5 12600KF
品牌+系列+定位+代数+性能+是否可超频+有无核显

+ 系列：Core 酷睿、Pentium 奔腾、Celeron 赛扬、Xeon 至强、Atom 凌动
+ 定位：同一代中，数字越大，性能越强
+ 代数：越大越新
+ 性能：数字越大频率越高
+ K 表示不锁频，F 表示不带集成显卡，T 表示低功耗版，X/XE 表示至尊旗舰版，KS 表示官方超频版，U 表示低电压，H 表示标压，Y 表示超低电压，HK 一般用在高端发烧级 CPU，G 接数字表示核显强弱

### AMD CPU 命名规则

AMD Ryzen R5 5600X
品牌+系列+定位+代数+性能+是否支持 XFP

+ 系列：Ryzen 锐龙、EPYC 霄龙
+ 定位：同一代中，数字越大，性能越强
+ 代数：越大越新
+ 性能：数字越大频率越高
+ X 表示支持 XFR 技术，G 表示属于 APU，XT 是 X 的加强版，U 表示低电压，H 表示标压，HX 一般用在高端发烧级 CPU 上，HS 相当于 H 功耗略低
